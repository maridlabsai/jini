# Jini Lexicon

## 1. Purpose

Jini uses short, practical canonical names for user-facing commands, artifacts,
packs, profiles, extensions, and states.

Jini documentation, schemas, workflow packs, and CLIs MUST use these names.

## 2. Naming Rules

- prefer one-word names
- prefer verbs for operations
- prefer concrete nouns for artifacts
- prefer names that still read clearly outside software engineering
- prefer names that work equally well in docs, commands, and conversation
