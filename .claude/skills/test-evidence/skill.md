# Test Evidence

Use this skill before claiming Jini is alpha-ready, release-ready, or aligned with the PRD.

## Procedure

1. Identify the exact claim.
2. Find the gate, transcript, or artifact that proves it.
3. If proof is missing, downgrade the claim or add the missing gate.
4. Quote counts and percentages only from tool output.

## Output

Return `claim`, `evidence`, `confidence`, and `missing proof`.
