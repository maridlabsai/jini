The core Jini tool stays public.

That includes:

- runtime
- docs
- examples
- tests

Paid work later is for:

- adoption help
- implementation help
- onboarding
- custom integrations
- enterprise support

The rule is simple:

**charge for help and trust, not for basic access to the core tool.**
