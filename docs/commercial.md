<p class="page-lead">The core Jini tool stays public. Paid work is for helping teams adopt it well, not for charging basic access to the core runtime and docs.</p>

<div class="checklist-grid">
  <div class="checklist-card">
    <h3>What stays public</h3>
    <p>Runtime, docs, examples, and tests stay in the public product surface.</p>
  </div>
  <div class="checklist-card">
    <h3>What paid work covers</h3>
    <p>Adoption help, implementation help, onboarding, custom integrations, and enterprise support.</p>
  </div>
  <div class="checklist-card">
    <h3>The rule</h3>
    <p><strong>Charge for help and trust, not for basic access to the core tool.</strong></p>
  </div>
</div>
