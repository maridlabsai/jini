# Support

## Community Support

Use GitHub Issues for:

- reproducible bugs
- documentation gaps
- clear feature requests

Use GitHub Discussions for:

- questions
- workflow design discussion
- pack ideas
- adoption feedback

Community support covers the public framework:

- bugs in the public repo
- documentation gaps
- install friction in the public install path
- public feature requests

Commercial support is separate:

- repo-specific implementation
- workshops
- custom workflow mapping
- custom integrations
- enterprise governance needs
