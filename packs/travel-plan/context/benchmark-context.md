# Travel Plan Benchmark Context

Use this pack when the user needs a structured trip-planning workflow instead
of loose notes.

Assume a traveler needs:

- explicit dates
- explicit budget guardrails
- a coherent itinerary
- visible logistics and contingency steps

The point of this pack is not booking automation.

The point is to prove that the same Jini kernel can support a non-software,
consumer-style workflow with:

- canonical state
- tasks
- evidence
- approvals when needed
